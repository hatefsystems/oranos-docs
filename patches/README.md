# Oranos Chromium Patch Series

This directory is reserved for Oranos-specific commits exported with `git format-patch` from a local Chromium source checkout.

There are currently **no patches**. The Oranos source baseline has not yet been built or branded.

Keep patches ordered, narrowly scoped, reviewable, and applicable to the revision specified in `config/chromium-revision.env`. Never silently replace failing patches with broad rewrites of upstream security logic. See [upstream maintenance](../docs/upstream.md).
